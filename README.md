# 出費管理アプリケーション（ExpenseManager_japanese）

- 日々の出費を記録・管理が可能なPython　GUIアプリケーションです。
- 入力された出費項目と金額を集計して合計額が大きい順に一覧表示が可能。
- 割合を示す円グラフによる直感的な分析も可能。
- 記録・管理だけでなく、集計と分析によって実際の出費の改善までサポートできる構造を目指しています。

## 主な機能
- 出費内容の表への入力（日付、出費項目、金額、メモ）
- 表による入力データの一覧表示と編集（削除）
- 入力データの集計と一覧に表示
- 円グラフによる出費項目ごとの割合の可視化
- 入力データの保存・読み込み（json形式）
- キーボードショートカットによる操作補助（出費内容の入力のみ）

## 開発環境と使用技術
- Visual Stadio Code
- Anaconda3
- Python 3.12.7
- PySide6 (GUI)
- matplotlib (円グラフ表示)
- pandas(データ集計)
