# 出費管理アプリケーション（ExpenseManager_japanese）

- 日々の出費を記録・管理が可能なPythonで記述したGUIアプリケーションです。
- 出費情報を集計して降順に並んだ合計金額一覧と円グラフで割合とその数値を可視化します。
- 過去の出費のうち最も高い項目などが直感的にわかる仕組みなので、未来の出費を抑えるきっかけ作りを後押しします。

\
　
# Excel家計簿よりも早く入力・分析できるように
\
　
## 1つの出費情報の入力は「4秒」で可能
\
　
### 『Excel家計簿で面倒なセル移動がないから、不要な時間がかかりません』
\
\
\
そのほか使いやすくした点
- ウィジェットが縦にレイアウトされたGUIで直感的な使いやすさを表現
- 出費項目は実生活で使うカテゴリー（食費や生活消耗品費など）をラベルした9個＋任意のカテゴリーが入力可能になる「その他」1個のラジオボタングループとしてまとめて実装
- 出費情報を入力するショートカット（Enter）の実装
- 入力後は金額が自動リセットされるなど不要な操作を排除
- 出費カテゴリー別の合計金額一覧や円グラフも出費情報の入力とともに更新されるため、グラフの作成操作も不要

\
出費を入力・管理・分析することだけに特化したアプリケーションを目指しました。

## アプリケーションの基本操作
- 「出費入力タブ」で「日付・出費項目・金額（半角数字）」の出費情報を入力します。メモは任意で入力してください。
- 出費情報を入力できたら「表へ入力」ボタンをクリックまたはEnterキー（ショートカット）を押してください。\
  その後「出費一覧タブ」の表に入力した4項目が追加されます。
- 出費情報の入力ミスの場合は「出費一覧タブ」に切り替え、表の中で該当する行番号もしくはいずれかの出費情報を選択し、下部にある「行を削除」ボタンで削除することができます。
- 表への追加と同時に「分析タブ」では「出費一覧タブ」の表に基づいて出費項目ごとの合計一覧と割合を確認できる円グラフ、出費額の合計が更新されます。

## 保存と読み込み、「入力項目をリセット」について
- 保存や読み込みは「出費入力タブ」の下部のボタンから実行できます。上書き保存は、ファイルの保存または読み込みを行うと実行できます。
- 「入力項目をリセット」ボタンは「出費一覧タブ」に入力した項目を全てリセットします。新しいファイルを作りたい場合にも有効です。
