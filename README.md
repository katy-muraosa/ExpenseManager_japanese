# 出費管理アプリケーション（ExpenseManager_japanese）

- 日々の出費を記録・管理が可能なPython　GUIアプリケーションです。
- 集計一覧と円グラフによる可視化によってそれぞれの出費項目の割合と合計金額が一目でわかります。
- 過去の出費の増加の原因が直感的にわかる仕組みを実装し、未来の出費を抑えるきっかけ作りを後押しします。

# クイックユーザーマニュアル
- 「出費入力タブ」で「日付・出費項目・金額（半角数字）」で入力します。メモは任意で入力してください。
- 入力できたら「表へ入力」ボタンをクリックまたはEnterキーを押してください。\
  「出費一覧タブ」の表に入力した4項目が追加されます。
- 表への追加と同時に「分析タブ」では「出費一覧タブ」の表に基づいて出費項目ごとの合計一覧と割合を確認できる円グラフ、出費額の合計が更新されます。

# 仕組み
## メインウィンドウ
「出費入力」「出費一覧」「分析」の3つのタブで構成されています。

## 出費入力タブ
具体的な出費に関する内容を入力するタブです。\
出費入力タブは大きく分けて2つの機能を持ちます。
#### ①基本出費項目と表への入力
#### ②表データの保存・上書き保存と読み込み、表データと読み込みファイルのリセット
入力すべき基本項目は4つあり、メモを除いた3項目を正しく入力してください。\
以下、それぞれの項目の概要です。

- 日付選択：\
カレンダーウィジェットを通じて年月日を選択します。デフォルトは今日の日付です。
- 出費項目：\
ラジオボタン形式で出費のカテゴリーを選択します。\
どのカテゴリーにも当てはまらない場合は、\
「その他」のラジオボタンを選択することで任意の項目として入力できます。
- 金額：\
金額を入力します。半角数字に限り入力可能です。
- メモ：\
任意のメモを入力できます。入力必須ではありません。
